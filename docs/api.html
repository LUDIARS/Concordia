API リファレンス

base: · loopback bind。各エンドポイントは トグルで展開 すると用途・パラメータ・レスポンス・実装位置を確認できる。 内容は src/ の実ルート定義から抽出（ 項目の REST エントリ、3 本の MCP サーバ / 15 tools、24 種の WS·SSE イベント）。一部の admin 行は GET·PUT を 1 項目にまとめている。

MCP サーバ / tools

3 本の stdio MCP サーバを同梱。別 AI session（Claude Code / Codex / Gemini）から Concordia 状態を直接読み書き / 操作できる。

WebSocket / SSE イベント

/ws（WebSocket）と /v1/stream（SSE firehose）で ConcordiaEvent を配信。 target_session_id 付きイベント（session.inject 等）は該当 ?session= クライアントのみに配信される。 /v1/processes/:name/stream は当該プロセスの process.log / process.exited のみ（backfill 100 行）。
