アーキテクチャ / ドメイン関連グラフ

src/ の import を解析して得たドメイン（モジュール）と依存関係。ノードをクリックすると役割・依存先・被依存が表示される。 ドラッグで移動、ホイールでズーム、凡例クリックでカテゴリの表示/非表示を切り替えられる。ノードサイズは 被依存数 に比例する。

エッジ A→B は「A が B を import / 呼び出す」を意味する。フォーカス時のみ矢印を表示。

カテゴリ（クリックで絞込）

ドメイン一覧

中心となるのは db（ほぼ全ドメインが依存する永続化基盤）、shared（config/logger/型）、events（実行時の協調ハブ）。 app / server は composition root（最大の fan-out）。
