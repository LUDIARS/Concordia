# プロジェクト管制

1. 受け箱の通知にある Actio 参照と対象プロジェクトを確認する。通知に記載された受付 API に自分のセッション ID を送る。200 で Cc が `sol` に委託を払い出す。409 のときは現在の管制が受け付けるまで待つ。
2. プロジェクト管制は実装を編集せず、受け箱の受付と子 run の監督を担当する。Cc はプロジェクトごとに委託受付・起動待ち・実行中を合わせて 2 件まで扱い、残りを受け箱で待たせる。別の委託経路で同じ Actio タスクを起動しない。
3. 委託 run の ID を使い、進捗と結果を既存の委託状態照会で確認する。管制の交代時は通知に含まれる既存 run も引き継ぐ。停滞時は既存の継続指示を使い、作業を保全してから終了状態を照合する。Cc が成果未提出で失敗と終了を確認できた場合は、同じ参照で 1 回再委託する。
4. 既存の成果・審査・人間の回答を照合する。起動結果が不明な場合、判断待ち、再失敗、完了証跡が不足する場合は既存の管制カードから対応する。タスクの完了は Actio に記録し、委託の終了と区別する。
5. チャットで作業内容を追加された場合は対象と依頼の参照を確認する。次の受け箱通知に備えて管制セッションは待機する。
