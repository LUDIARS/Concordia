# クラウド作業の観測と確認

2026-10-17 neco の実装指示。既存 Actio 参照は
`actio:b0483e60-297d-4dc6-a4bf-54e1f8752e04`。タスクの状態をこの文書で代替しない。

## 価値と所有者

UX-CC-W2/W4/W5、UX-CC-S3/S5。利用者が作業の停止や回答待ちを見失わない。
cloud-observation は支援境界。観測イベント、受信時刻、質問と回答の対応を所有する。
成果の検査・審査・Actio 完了状態は所有しない。

## 設計・受入条件

- CC-OBS-01: attempt ごとにスレッドを一つ紐付ける。本社の「クラウド」フォーラムを使う。
  フォーラム自体は既存 Discord layout が所有し、保存済み ID を優先して再利用する。
- CC-OBS-02: heartbeat、progress、preview、question、finished、failed を扱う。
  クラウドの自己申告と成果物の検証済み状態を区別する。
  受信後 180 秒無通知は通信途絶。実行成功・失敗には変換しない。
- CC-OBS-03: event ID と連番で再送を照合。同じ ID の内容変更、逆順、完了後の追加を拒否する。
  heartbeat は質問待ちを解除しない。回答は一致する質問 ID にだけ保存する。
- CC-OBS-04: 本社が束縛した run / forum / thread だけに投稿する。
  クラウドから Discord の送信先を指定させない。全投稿でメンションを無効にする。
  認証キーや任意の環境変数・生ログは送らず、工程の要約を送る。
- CC-OBS-05: preview は受信・容量・画像形式を検査したファイルだけを扱う。
  任意 URL の代理取得はしない。質問と回答は永続化し、配達と受領を区別する。

工程通知は最大 1000 文字、プレビューは PNG/JPEG とし最大 8 MiB。
heartbeat は 30 秒間隔を推奨。画面のライブ配信は今回の対象外。
質問は作業を停止して回答を待つ。フォーラムの単なる会話を実行許可へ変換しない。

## 配線と復旧

受信・生存判定は Discord 配達から分離する。既存クラウド受信 PR #3148 を依存として取り込み、
実行ごとの認証を共有し、クラウド送信・フォーラム配達・回答取得を接続する。
この版の配達先は本社フォーラムに限定し、子会社スコープの実行は観測有効時に起動前拒否する。
作業対象は target/attempt の組で識別する。専用 observations.sqlite の状態・イベント・画像は
受信プロセスと Discord adapter が transaction を通じて更新し、他の業務DBを変更しない。
回答保存済みとクラウド再開確認を分け、生存通知だけでは回答受領を認定しない。
画像は PNG/JPEG signature を検査する（画像デコードや内容の安全性を保証しない）。
1画像8 MiB、1実行32 MiB、1実行10,000イベントを上限とする。

設定は本社 Cc と受信プロセスで `CONCORDIA_ARTIFACT_ROOT` を共通にする。
`CONCORDIA_CLOUD_OBSERVATION_ENABLED=true`、`CONCORDIA_CLOUD_OBSERVATION_HOST=tailscale`、
`CONCORDIA_ARTIFACT_PORT` はサービス所有catalogで定義。必要な場合だけ
`CONCORDIA_CLOUD_OBSERVATION_URL` で Tailnet IPv4 の origin を指定する。
保存フォルダは起動前に用意する。受信サービスの起動は Excubitor 経由。
Discord adapter は15秒ごとに最大200実行を照合する。記録200件に達したら新しい実行の
観測受付を明示的に拒否し、既存の回答待ちを表示対象から落とさない。
アーカイブ・ページングは未対応で、継続運用前の制限事項として扱う。
質問への回答は、Ccが配達した質問投稿へのDiscord返信、または `/回答 質問ID 回答内容`。
返信は配達時に保存したメッセージID・スレッド・run・質問IDと照合する。
過去の質問、別スレッド、未配達の投稿への返信を現在の回答に流用しない。
本社セッション操作を許可された人だけを受け付ける。
通常の会話やBot投稿は回答にしない。保存直後の返答は受領保証ではない。
送信結果不明は照合待ちとし、スレッドや投稿を無条件に再生成しない。
復旧は対象変更を revert。既存の成果物と質問・回答の記録を削除しない。

実クラウド接続、Discord 実投稿、停止・再開試験は実施結果を別途記録する。
