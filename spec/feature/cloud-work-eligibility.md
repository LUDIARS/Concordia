# 標準クラウドへの委託条件

2026-10-16 neco 指示。価値 UX-CC-W2/W5、不変条件 CC-CLOUD-09。
Codex Cloud / Claude Code Cloud 共通で、次の4条件をすべて満たす依頼だけを対象とする。

1. リポジトリサイズが50 MB以下。
2. 標準クラウドで環境を準備でき、大きい別プロジェクトのcloneを必要としない。
3. 成果物の生成に負荷がかかる。
4. 成果物の操作・判断などにLLMの指示が必要。

モデリング、Rust等のアプリのビルドとテスト、学習、レンダリングは候補例であり、
名前や言語だけで3・4をtrueにしない。単に重い決まったコマンドを回すだけで
LLMが不要な依頼は対象外。軽い文章編集も対象外。

サイズの単位は50,000,000 bytes（50 MB）として比較する。測定元・対象revision・
clone方式は呼出側の証拠として保持し、圧縮した一部ファイルのサイズを未確認の
リポジトリ全体のサイズの代用にしない。Git履歴/LFS/submoduleの取得範囲を含む
実際の準備経路のサイズを確認する必要があり、未測定値を0にしない。

条件の証拠が不足した場合は未確認理由を返す。ユーザーの例示Tokyo2070、Synergos、
FgとLDの重たいレンダリングも候補として
扱い、プロジェクト名による恒久的な許可を設けない。依頼と入力revisionごとに判定する。

この4条件は必要条件。GPU・Blenderバージョン・メモリ・時間制限・認証・公開済み
入力revision・成果物回収の準備も、実行前の別の検査に通る必要がある。trueは起動許可、
課金許可、実行済み、GPU利用可の意味ではない。対象外を黙ってローカル起動しない。

## 実装範囲と受入条件

`src/cloud-work/eligibility.ts` はI/Oを持たない判定部品。`submission.ts` は送信前に
この判定を適用する。Codex CLI・Claude routineのadapterと再送防止のintent記録を
実装し、`/v1/delegation/cloud`、委託画面、委託MCPへ接続した。通常のローカル委託は
従来どおり。クラウド対象の設定、実アカウントでの試験、本体への反映は別途必要。

- 全条件true、サイズが上限ちょうどなら対象。
- 1条件でもfalse、サイズ超過、欠落、NaN、負数、非整数なら対象外。
- 同時に複数条件が不足している場合も理由を失わない。
- 大きい依存projectのcloneが必要なら、対象repo自体が小さくても対象外。
- 起動経路への接続後、両providerで起動副作用より先にこの判定を適用する。

テストは同じ変更単位に追加する。実行結果は別途記録する。
