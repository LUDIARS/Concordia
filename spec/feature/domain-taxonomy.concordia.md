# Domain taxonomy: concordia

Generated by the self-adjustment pipeline ([domain-retune](./domain-retune.md)). Iterations: 3.
This file mirrors `spec/data/concordia.taxonomy.json` and `spec/data/ontology/*.domain.json`.

## chat-platforms

Bidirectional chat-platform integration that surfaces session state and accepts control input over Discord and Slack, including reaction-driven dispatch.

- **discord** - Discord lifecycle, routing, projection, interaction ports, control UI, and command handlers.  `paths: (^|/)src/discord(?:/.*)?$`
- **slack** - Slack lifecycle, routing, projection, modal handling, and session mirroring repos.  `paths: (^|/)src/slack(?:/.*)?$`
- **chat-rendering** - Shared chat rendering, actionable-message parsing, and platform-neutral chat helpers (src/chat).  `paths: (^|/)src/chat/[^/]+$`
- **reaction-workflow** - Transport-neutral lifecycle, emoji-to-action mapping, workflow planning, and runner harness.  `paths: (^|/)src/platform(?:/.*)?$`

## agent-delegation

Agent delegation, subsidiary bots, harness sessions, and advisory testing claims that coordinate work beyond a single session.

- **delegation-coordination** - Delegation templates, parent/child run tracking, portable prompts, and injected coordination messages.  `paths: (^|/)src/delegation(?:/.*)?$`
- **subsidiary-harness** - Subsidiary bot runtime, budget tracking, harness rules, and harness-session API support (src/subsidiary, src/harness).  `paths: (^|/)src/subsidiary/[^/]+$, (^|/)src/harness/[^/]+$`
- **testing-claims** - Advisory service-test claims and branch-watch notifications used to avoid restart/test collisions (src/testing).  `paths: (^|/)src/testing/[^/]+$`

## http-interface

External access surfaces: the HTTP/Hono REST API that hooks report to, the MCP server, and the web monitoring frontend.

- **rest-api** - Hono route groups and purpose-specific dependency ports for sessions, spawn, reports, and other v1 endpoints.  `paths: (^|/)src/api(?:/.*)?$`
- **web-monitor** - Vite+React Foundation UI pages, components, and hooks for live monitoring (web/src).  `paths: (^|/)web/src/pages/[^/]+$, (^|/)web/src/pages/settings/[^/]+$, (^|/)web/src/[^/]+$, (^|/)web/src/components/[^/]+$, (^|/)web/src/hooks/[^/]+$`
- **mcp-server** - MCP tool surface exposing Concordia queries to agents (src/mcp).  `paths: (^|/)src/mcp/[^/]+$`
- **web-client** - Browser-side UI library (rendering, connection, event wiring) and host/config loading that front the HTTP interface  `paths: (^|/)web/src/lib/[^/]+$, (^|/)web/[^/]+$`

## session-coordination

Core purpose: track concurrent AI coding agent sessions 窶・register, share progress, detect lost sessions, recover from jsonl, resume, and generate end-of-session reports.

- **session-lifecycle** - Session registration, heartbeat, end flow, spawn, compaction, and reaper control.  `paths: (^|/)src/control(?:/.*)?$`
- **worktree-automation** - Parallel git worktree detection and management for same-repo/branch sessions (src/work, src/processes).  `paths: (^|/)src/work/[^/]+$, (^|/)src/processes/[^/]+$`
- **session-reports** - LLM summarization plus structured aggregation of session events into reports and session-log artifacts (src/report, src/session-logs).  `paths: (^|/)src/report/[^/]+$, (^|/)src/session-logs/[^/]+$`
- **lost-recovery** - Heartbeat sweeper, jsonl transcript parsing, and lost-session candidate handling (src/providers, src/work).  `paths: (^|/)src/providers/[^/]+$`

## runtime-orchestration

Process bootstrap and in-process composition: server entrypoints, route composition, worker modes, event bus, and periodic runtime loops.

- **bootstrap-composition** - Explicit boot phases, resource ownership, chat/cost mode selection, startup, and symmetric shutdown.  `paths: (^|/)src/bootstrap(?:/.*)?$`
- **server-entrypoints** - Top-level server/app/event modules and worker entrypoints that connect the runtime graph.  `paths: (^|/)src/(app|server|events|errors|sweeper|chat-worker|cost-worker|discord-worker)\.ts$`

## persistence

Durable state and cross-cutting infrastructure: SQLite repositories for all entities plus shared config, secrets, and auth helpers.

- **repositories** - SQLite-backed repos for sessions, participants, channels, PRs, and more.  `paths: (^|/)src/db(?:/.*)?$`
- **config-secrets** - Config loading, secret resolution, encryption, and bearer extraction (src/shared, src/auth).  `paths: (^|/)src/shared/[^/]+$, (^|/)src/auth/[^/]+$`

## observability

Cost, resource, and time-based reporting: aggregating spend, sampling host metrics, and scheduling daily/morning/stat rollups.

- **cost-tracking** - Cost feed aggregation and usage rate reading across providers (src/cost).  `paths: (^|/)src/cost/[^/]+$`
- **host-metrics** - Host process/resource snapshots and capture (src/metrics).  `paths: (^|/)src/metrics/[^/]+$`
- **scheduled-reports** - Daily, morning, and stat schedulers driving periodic reports (src/daily, src/morning, src/stat).  `paths: (^|/)src/daily/[^/]+$, (^|/)src/stat/[^/]+$, (^|/)src/morning/[^/]+$`

## governance

Policy and workflow steering: a rule engine that proposes/enacts actions, PR queue reconciliation, role prediction, and admin configuration toggles.

- **pr-queue** - PR ingestion, reconciliation, and queue building (src/pr).  `paths: (^|/)src/pr/[^/]+$`
- **rules-engine** - Rule evaluation, proposal, and action execution (src/rules, src/role).  `paths: (^|/)src/rules/[^/]+$, (^|/)src/role/[^/]+$`
- **admin-settings** - Workspace, workflow, and runtime settings stores behind the AdminState compatibility facade.  `paths: (^|/)src/admin(?:/.*)?$`

## analysis-core

Core Anatomia analysis engine (session cache, parsing) together with skill frontmatter parsing/analysis and model-catalog seeding that feed the analysis pipeline

- **anatomia-engine** - Core Anatomia analysis engine (session cache, parsing) together with skill frontmatter parsing/analysis and model-catalog seeding that feed the analysis pipeline  `paths: (^|/)src/anatomia/[^/]+$, (^|/)src/skills/[^/]+$, (^|/)src/library/[^/]+$, (^|/)src/model-catalog/[^/]+$`

## tooling
