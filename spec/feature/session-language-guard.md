# 言語補正 — 英語に流れたセッションを日本語へ戻す

> 2026-10-01 neco 指示「Opus が急に英語しか話さなくなることがある。傾向的に FINAL ANSWER の前から英語で話すのと、
> 継続するようなので、FINAL ANSWER の英語を受け取る前にフックか何かで日本語で補正できるような inject を入れてほしい」。

- 価値: [UX-CC-W4](../ux/product.md) (通知を見れば今必要な判断が分かる)。Discord で受け取る報告・質問が英語になると、
  何を判断すればよいかが読み取りにくくなる。
- 利用者に起きる変化: セッションが途中発言から英語に流れても、最終回答の前に日本語へ戻る。最終回答まで英語で
  書き終えていた場合も、続けて日本語の言い直しが届く。

## 1. 起きていること

- 英語化は最終回答の前の途中発言 (commentary) から始まり、そのまま最終回答まで続く。
- コンテキスト圧縮の要約が英語で書かれ、その後の発言が要約に引きずられて英語になる例がある (2026-10-01 本社セッション)。
- Claude Code の Stop フックで最終回答を止めても、Lictor は transcript を書かれた順に中継するので、英語の最終回答は
  先に Discord へ届いてしまう。補正は **途中発言の段階** で入れる必要がある。

## 2. 判定

**Requirement ID: `SPEC-LANG-DETECT`** — `src/control/language-drift.ts`

- コード片 (```` ``` ````)・インラインコード・URL・パス (`/` か `\` を含む ASCII の語) は文章ではないので数えない。
- 英単語 (英字 2 文字以上) が 12 語以上あり、ひらがなが英単語数の 1/4 未満なら英語の発言とみなす。
  日本語の文には助詞・活用語尾のひらがなが必ず入り、英文に引用された部署名やコマンド名 (漢字・カタカナ) では増えない。
- 英単語が 12 語未満の短い発言は判定しない。

## 3. 補正

**Requirement ID: `SPEC-LANG-GUARD`** — `src/control/language-guard.ts`

- Concordia が受け取る assistant の発言 (`transcript.frame` の `kind=text`, `role=assistant`) を、途中発言・最終回答を
  区別せずに見る。英語なら `auto:language-guard` を source にして次の文を inject する。

  ```text
  [言語補正] 直前の発言が英語になっています。
  このセッションの応答は日本語で書いてください (コード・コマンド・固有名詞・引用はそのままで構いません)。
  作業の途中なら、そのまま日本語で続けてください。最終報告まで英語で書き終えていた場合は、その要点を日本語で言い直してください。
  ```

  作業中なら次の tool 結果と一緒に届き、最終回答の前に日本語へ戻る。ターンが終わっていれば、日本語の言い直しを返す。
- inject は他の Cc 由来 inject と同じく session thread に 1 行で転記される (`言語補正: 直前の発言が英語になっています。`)。
- 設定 `session.language_guard_enabled` (WebUI、DB `admin.language_guard_enabled`、既定 ON) で止められる。

不変条件:

| ID | 条件 |
|---|---|
| CC-LANG-INV-01 | コード・URL・パスだけが英語の発言、短い発言は補正しない |
| CC-LANG-INV-02 | 補正したセッションには、日本語の発言が出るか人間の発言が届くまで補正を送らない。送る間隔は 120 秒以上空ける |
| CC-LANG-INV-03 | 未回答の質問があるセッション・active でないセッション・再放流された古い発言 (300 秒より前) には送らない |

状態の所有者: 補正済みかどうかは `startLanguageGuard` のメモリ上だけに持つ (再起動で消えてよい。消えても最悪 1 回多く
補正するだけ)。セッション終了・lost で捨てる。

## 4. 範囲外

- Claude Code のフック (Stop で最終回答を差し止める) は使わない (§1 のとおり中継を止められない)。
- 圧縮直後の予防 inject は入れない。待機中のセッションに送ると新しいターンを起こしてしまうため。
- 日本語以外を既定言語にする設定は持たない。
