# Local PR 内容がコミット件名だけになる

## Evidence

- 2026-08-08 に、Cc / Revisor 経由で起動した LLM の local PR 本文がセッション ID とコミット件名だけになり、何の作業か分からないと報告された。
- 既存の `src/pr/local-pr-submission.ts` は最新コミット件名を title にし、本文にも件名一覧しか入れていなかった。
- タスクワークフローの task md にはタイトル、目的、完了条件という設計の正本が既にあるが、提出処理は参照していなかった。

## Cause

PR 提出用の内容契約が無く、Cc は task md と無関係にコミット履歴から人間向け本文を組み立てていた。Revisor 側も `body` を任意の自由文字列として扱っていたため、不十分な PR がレビューとテストへ入れた。

## Fix

- Cc は提出 session と `source_session` が一致する worktree 上の task md を読み、タイトル、実装内容、受け入れ条件を日本語の PR 内容として提出する。
- task md が不足・不完全・過大な場合、Cc は Revisor の内容契約を満たすコミット件名ベースの本文へフォールバックする。
- Revisor は title と `## 実装内容` / `## 受け入れ条件` のある PR 内容を必須にし、明示本文も含めて不備ならキュー投入前に reject する。

## Regression expectation

- 設計済み task md から提出した PR は task の目的と完了条件を別セクションで表示する。
- task md が無い、条件が空、内容契約外、または上限超過でも、契約準拠のフォールバックにより提出自体は 400 で失敗しない。
