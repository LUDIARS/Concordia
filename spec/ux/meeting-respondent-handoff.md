# 価値 UX-CC-MEETING-LINK-W1

組織の参加者が、公開チャンネルに個人用リンクを晒さず、Discord で確認された自分として予定に回答できる。失うと困る状態は「他人の回答を編集せず、自分の回答へ戻れること」。UX-CC-W1 の対象・権限の分離を支える。

シナリオ UX-CC-MEETING-LINK-S1: BOTTEST の投稿ボタン → 現在の所属を照合 → 本人にだけ5分・一回限りのリンク → Ae で明示的に紐付け → 当該予定だけの回答者として利用する。
期限切れ・所属喪失・結果不明は新しいリンク取得へ案内する。既存の匿名回答や Cernere アカウントを統合しない。

この UX は設計案。人間による実機評価は未実施。
